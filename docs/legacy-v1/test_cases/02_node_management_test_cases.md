# 02 — Test Cases: Quản lý Node (Node Management)

Phân hệ Quản lý Node thực hiện lưu trữ, hiển thị danh sách các máy chủ cần giám sát, hỗ trợ các thao tác CRUD và thực hiện mã hóa các thông tin đăng nhập SSH nhạy cảm (Password, Private Key) trước khi ghi xuống SQL Server.

---
