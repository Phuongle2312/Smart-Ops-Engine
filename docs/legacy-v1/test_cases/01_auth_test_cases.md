# 01 — Test Cases: Xác thực & Phân quyền (Auth)

Phân hệ Xác thực & Phân quyền quản lý tài khoản người dùng, cấp phát token bảo mật (Access Token & Refresh Token), cấu hình phân quyền truy cập API (Spring Security) và hiển thị giao diện phù hợp với vai trò của người dùng (`ROLE_ADMIN` vs `ROLE_VIEWER`).

---
