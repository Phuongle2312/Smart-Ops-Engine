# 04 — Test Cases: Quản lý Sự cố (Incident Management)

Phân hệ Quản lý Sự cố chịu trách nhiệm ghi nhận, theo dõi, phân loại trạng thái (OPEN, MONITORING, ACKNOWLEDGED, RESOLVED), lọc tìm kiếm sự cố và cung cấp công cụ xử lý sự cố cho vận hành viên.
