# 03 — Test Cases: Health Check Scheduler (Health Check & Giám sát)

Health Check Scheduler là trái tim của hệ thống giám sát tự động, thực hiện quét định kỳ tài nguyên (Disk/CPU/RAM) của các máy chủ đang hoạt động qua SSH hoặc API local, so sánh các chỉ số với ngưỡng thiết lập để tạo sự cố và gửi cảnh báo.

---
