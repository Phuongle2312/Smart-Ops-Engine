# 05 — Test Cases: Cảnh báo đa kênh (Alert Notifications)

Phân hệ Cảnh báo đa kênh đảm nhận vai trò phân phối thông tin sự cố tới các kênh liên lạc (Email SMTP, Slack/Discord Webhooks) dựa trên độ nghiêm trọng và cung cấp hệ thống thông báo tức thời (Toasts) trên giao diện người dùng.
